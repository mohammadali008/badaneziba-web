# بدن زیبا — لندینگ فارسی و راست‌چین

سورس وب‌سایت [سالن بدن زیبا](https://badaneziba.com/) — وکس و اپیلاسیون تخصصی آقایان در تهران.

مخزن: [mohammadali008/badaneziba-web](https://github.com/mohammadali008/badaneziba-web)

## ساخت، بررسی و انتشار

```bash
npm run build
npm run check
```

برای ساخت و بررسی به Node.js نسخه ۲۰ یا جدیدتر نیاز است؛ نصب پکیج لازم نیست. GitHub Actions نیز همین بررسی‌ها را برای شاخه main و pull requestها اجرا می‌کند. مراحل Cloudflare Workers در [راهنمای انتشار](DEPLOYMENT.md) آمده است. فرمان build: `npm run build`؛ فرمان deploy: `npx wrangler deploy`؛ نام Worker: `badaneziba`.

عکس‌های خام در img و اسکرین‌شات‌های محلی در preview در Git نگهداری نمی‌شوند. رسانه‌های بهینه و مجوز فونت‌ها در assets موجودند. کدهای تولید ویدیو ابزارهای اختیاری توسعه هستند و برای اجرای وب‌سایت لازم نیستند.

## فناوری

HTML، CSS و JavaScript خالص؛ بدون نیاز به build یا نصب پکیج برای اجرای سایت.

## اجرا

در پوشه پروژه اجرا کنید:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

سپس http://127.0.0.1:4173 را باز کنید. برای انتشار، دستور `npm run build` را اجرا و از خروجی `dist` استفاده کنید. پوشه‌های `img`، `scripts` و `preview` برای اجرای سایت روی هاست لازم نیستند.

## تماس و هماهنگی نوبت

همه دکمه‌های نوبت‌دهی به بخش `#contact` می‌روند. این بخش دو لینک مستقیم دارد:

- تماس: `tel:+989127200944`
- واتساپ: `https://wa.me/989127200944` با متن اولیه قابل ویرایش توسط کاربر.

شماره تاییدشده سالن: **09127200944**. شماره و تنظیمات ویدیو در `site-config.js` قرار دارند. لینک‌های HTML نیز برای کارکرد بدون JavaScript همین شماره را دارند؛ هنگام تغییر شماره، مقدارهای HTML و فایل تنظیمات را به‌روزرسانی کنید. فرم، تقویم، ثبت درخواست و ذخیره اطلاعات وجود ندارد. سایت هیچ پیامی را به‌صورت خودکار ارسال نمی‌کند.

## موشن انیمه‌ای وکس آقایان

ویدیوی فعال پس‌زمینه `assets/media/anime-wax-film.mp4` است: ۱۲ ثانیه، ۲۴ فریم‌برثانیه و وضوح ۱۲۸۰×۹۶۰. شخصیت بزرگسال و خندان، با یک نیمه مودار سینه و نیمه صاف در کنار نوار وکس تصویرسازی شده است. تصویرسازی چهار فریم با ابزار داخلی ImageGen انجام شده و حرکت پلک، دست و بدن با زمان‌بندی انیمیشن سل ساخته شده است. این موشن، تصویرسازی نمایشی است و به‌عنوان نتیجه واقعی خدمات یا تصویر مشتری معرفی نشده است.

پوستر: `assets/media/anime-wax-poster.webp`. طرح اصلی، روش تولید و پرامپت نهایی: `assets/media/anime-wax-production.md`. تولید مجدد ویدیو از طرح موجود: `python scripts/render_anime_film.py` با Pillow، NumPy و imageio-ffmpeg. اجرای خود سایت به این وابستگی‌ها نیاز ندارد. ویدیوی مسی قبلی از صفحه کنار گذاشته شده و صرفاً به‌عنوان فایل قدیمی باقی مانده است.

## محتوای فارسی، سئو و صفحه‌آرایی

عنوان و توضیحات متا، H1 و تیترهای بخش‌ها برای وکس و اپیلاسیون آقایان در تهران و برند بدن زیبا تنظیم شده‌اند. معرفی مصطفی ربیعی (استاد پشمچیون / پشمچیان)، سابقه از سال ۱۳۹۰، آدرس قلهک و ساعات همه‌روزه ۱۱ تا ۲۰ بر اساس اطلاعات صاحب مجموعه درج شده‌اند. هفت پرسش متداول با حذف تضمین‌های پزشکی بازنویسی شده‌اند. داده ساختاریافته BeautySalon و Person با تلفن، آدرس و ساعات کاری در HTML موجود است؛ امتیاز و نظر ساختگی درج نشده است.

تیترها راست‌چین‌اند. پاراگراف‌های توضیحی تراز دوطرفه، خط آخر راست‌چین، ارتفاع خط مناسب و فاصله حروف عادی دارند. در نمایشگرهای بسیار باریک تا ۳۶۰ پیکسل، تراز پاراگراف‌ها راست‌چین می‌شود تا فاصله بین واژه‌ها بیش از حد کشیده نشود. شکست اجباری سطر از متن‌های توضیحی حذف شده و متن انگلیسی و شماره تلفن، جهت مستقل دارند.

دامنه اصلی `https://badaneziba.com/` در canonical، Open Graph، robots.txt، sitemap.xml و داده ساختاریافته یکسان است. راهنمای انتشار GitHub + Cloudflare Workers و مراحل Search Console در [DEPLOYMENT.md](DEPLOYMENT.md) آمده است. با `npm run build` خروجی منتخب در dist ساخته می‌شود. انتشار عمومی و تأیید Search Console هنوز انجام نشده است. آماده‌سازی سئو تضمین رتبه یا ایندکس نیست.

منابع مراقبت پوستی: [راهنمای وکس AAD](https://www.aad.org/public/everyday-care/skin-care-basics/hair/how-to-wax)، [روش‌های حذف مو AAD](https://www.aad.org/public/everyday-care/skin-care-basics/hair/remove-unwanted-hair).

منابع بررسی: [عنوان و هدینگ صفحه در Google Search Central](https://developers.google.com/search/docs/appearance/title-link)، [الزامات صفحه‌آرایی عربی و فارسی W3C](https://www.w3.org/TR/alreq/).
